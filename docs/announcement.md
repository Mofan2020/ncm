# SkycMedia 停止安卓版支持

## 这次的决定

从现在起，SkycMedia 不再提供安卓安装包，官方维护的只有 Windows 和 macOS 两个桌面版本。已经发出去的安卓版还能继续用，只是不会再有更新。

桌面版会照常往下做，网易云音乐和 B 站的内容都在里面，播放、下载、收藏夹和账号登录都能用。

## 为什么停下来

安卓手机虽然用的是同一套系统，各家厂商却会在系统上做自己的改动。同一个安装包在模拟器里跑得好好的，换一台真机就可能出问题——我们遇到过模拟器上一切正常，装到某款手机上界面直接塌掉的情况。要覆盖市面上的机型就得一台台去试，代价一直涨。

界面本身也不顺利。安卓应用里的界面要靠系统自带的一个网页显示组件来渲染，各家手机带的这个组件版本不一样、能做到的事也不一样，老一些的手机上还会排版错乱。用这套办法做出来的东西，离「像个手机应用」还差得远。

改成安卓原生的写法重做一遍，等于把整个应用再写一次：下载、播放、歌词、登录、缓存这些全都要重来一遍。掂量过之后，觉得这个投入比同时维护两个桌面版本加起来还大，于是决定把力气放在 Windows 和 macOS 上，把这两个平台做扎实。

## 已经装了安卓版的人

手上现有的安装包可以接着用，功能不会再变，不会再收到新版推送。遇到问题可以在项目的 Issue 页面反馈，那是目前收集安卓问题的地方。

## iPhone 版

暂时没有做 iPhone 版的打算。苹果要求发布 iOS 应用先加入他们的付费开发者计划，这笔费用对这个项目来说不合适。

## 谢谢

谢谢一路以来用 SkycMedia 的人。停掉安卓版是我们自己的决定，如果给你添了麻烦，很抱歉。
